## Correction note (2026-07-31): fabrications in the first Figma Make build

An earlier version of this doc used `[Project Name]` placeholders and an invented "11 years" figure. Figma Make filled every gap with invented content. Full catalog of what it fabricated, so none of it survives into a later build:

**Fabricated projects:** Helios Search Platform, Pixel & Blueprint, Scribe Analyst Workspace. None exist.

**Fabricated metrics:** "340K-user search platform," "47 product teams," "12 product teams," "reducing task time by 40 percent." All invented. Note that the "40+ product teams" line in `tone-guide.md` is explicitly labeled a draft calibration example, not a verified fact, and it seeded this.

**Fabricated experience figure:** "11 YRS EXP." This one originated in the Figma prompt as a placeholder example and is my error. Anna has 20+ years per `facts.md`, career starting 2002.

**Image problems:** the hero and "behind the scenes" images are AI-generated stock, with visible spelling errors rendered into them ("ARCHITECTCRAL WIREFRAMES," "TECH COLLABARATION"). On a design portfolio specifically, misspelled text inside a hero image is disqualifying.

**Rule going forward:** never hand a generator a bracketed placeholder in a credential, company, title, date, or metric position. It will fill it, confidently and plausibly. Leave the field visibly empty or marked NEEDS REAL NUMBER instead.
